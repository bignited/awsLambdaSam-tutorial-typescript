# WanderLamb

WanderLamb is a simple, serverless API that suggests a travel destination based on your mood and budget.
Built with AWS SAM, Lambda, and TypeScript, it’s a lightweight, cloud-ready tool to inspire your next adventure.

## Features
- Suggests destinations based on mood tags and max budget
- Fully serverless with AWS Lambda & API Gateway
- Written in TypeScript with clear, modular structure
- Easy local testing with Docker and AWS SAM
- Supports query params like ?mood=offbeat&maxBudget=40
